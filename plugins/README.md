# NeonAmp starter plugins

These ten `.neonamp-plugin` files are portable JSON packages. Import them from NeonAmp's Plugins panel on Windows or Android. They contain no executable code and are validated before installation.

| Pack | Best for |
| --- | --- |
| Studio Monitor | neutral reference listening |
| Bass Foundation | controlled low-end lift |
| Vocal Clarity | speech and vocals |
| Night Listening | low-volume listening |
| Podcast Voice | spoken-word playback |
| Lo-fi Tape | warm, softened playback |
| Gaming Footsteps | positional detail |
| Classical Hall | orchestral ambience |
| Metal Guitars | guitar-forward mixes |
| Synthwave Drive | electronic music |

Enable one pack at a time when comparing tonal changes. Presets contributed by enabled packs appear in the Equalizer menu; supported effects are applied by the same native DSP pipeline on both platforms.
